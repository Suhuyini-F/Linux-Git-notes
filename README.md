# Linux-Git-notes
cd /home - where the personal files have
cd /bin - meaning binary value all the commands live 
cd /etc - where configuration live like network changes, user changes 
cd /tmp - temporary - anything important you can't put in there as when you turn off the system it won't to be there
cd /var - for things that changes a lot, log files - important for devops engineers
cd /usr - where programmes and application lives - in windows would be program file
cd /dev - everything is treated as a file, even CPU and keyboard
cd /opt - third party software goes there
cd /root - home folder for the super user acc kept separate for security reasons
